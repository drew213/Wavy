Start with the client's Klaviyo key.

The audit reads everything it needs from Klaviyo: twelve months of orders, every flow, and what email actually earned. A read-only key is enough, and it can't change anything in the account.

  1. In Klaviyo, open Settings → Account → API keys.
  2. Choose Create Private API Key and give it Read-only access.
  3. Copy the key. It starts with pk_. Paste it here.
